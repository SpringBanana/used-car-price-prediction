# 🚗 Used Car Price Prediction: Exploratory Data Analysis (EDA)

Разведочный анализ данных (EDA) вторичного автомобильного рынка США. Проект включает глубокую очистку сырых данных со специфической структурой пропусков (MAR/MNAR), исследование нелинейных взаимосвязей факторов ценообразования и формирование рекомендаций для построения моделей машинного обучения.

---

## 📌 Цели проекта

1. **Аудит и предобработка сырых данных:** приведение типов, выявление природы аномалий, очистка строковых представлений чисел.
2. **Логическая реконструкция пропусков:** восстановление скрытых значений без применения грубого удаления строк (`dropna`), снижающего репрезентативность выборки.
3. **Факторный анализ ценообразования:** исследование распределения таргета (`price`), оценка влияния возраста, пробега, бренда и истории владения на остаточную стоимость.
4. **Формирование ML-стратегии:** подготовка рекомендаций по feature engineering и выбору архитектур моделей для задачи регрессии.

---

## 🔍 Ключевые этапы работы

### 1. Предобработка и очистка данных
* **Синхронизация типов:** Столбцы `milage` (пробег) и `price` (целевая переменная) содержали текстовые символы (`$`, `mi.`, `,`). Выполнена очистка строковых шаблонов и перевод в тип `float`.
* **Логическое восстановление пропусков:**
  * `fuel_type` (4.24% пропусков): с помощью кросс-анализа текстового поля `engine` доказано, что 100% пропусков соответствуют электромобилям (`Electric Motor`). Присвоена категория `'Electric'`.
  * `clean_title` (14.87% пропусков): исходная карточка объявления предполагала флаг только при наличии чистого юридического статуса. Пропуски категоризированы как `'No'`.
  * `accident` (2.82% пропусков): матрица корреляции пропусков показала прямую связь с отсутствием чистых документов. Строки реклассифицированы в `'At least 1 accident or damage reported'`.
* **Сохранение объема данных:** Удалось сохранить 100% исходных наблюдений (4 009 строк), исключив потерю данных.

### 2. Анализ распределений и выбросов
* **Тяжелые хвосты (Heavy Tails):** Распределение `price` обладает сильной правосторонней асимметрией (экстремальные значения до 2.95 млн $ при медиане около 31 тыс. $).
* **Характер амортизации:** Падение стоимости от возраста носит экспоненциальный характер с резким обесценением в первые 5–7 лет и последующей стабилизацией тренда. Для сегмента старше 25 лет фиксируется перегиб за счет фактора раритетности.

### 3. Исследование взаимосвязей (Матрица $\phi_K$)
* Признак `brand` оказывает доминирующее влияние на базовый ценовой коридор, превосходя по силе связи формальный год выпуска и пробег.
* Юридическая чистота (`clean_title`) и отсутствие зафиксированных инцидентов (`accident`) выступают статистически значимыми факторами, формирующими премию к медианной цене.

## 📊 Результаты и рекомендации для Machine Learning

1. **Трансформация таргета:** Необходимость применения логарифмирования $\log(1 + \text{price})$ для подавления влияния правого хвоста и стабилизации дисперсии ошибок в линейных и нейросетевых моделях.
2. **Feature Engineering:**
   * Парсинг мощности (л.с.) и рабочего объема (л) из слабоструктурированной текстовой колонки `engine`.
   * Расчет удельной интенсивности эксплуатации: $\text{milage\_per\_year} = \frac{\text{milage}}{\text{age} + 1}$.
   * Сжатие кардинальности признаков `ext_col` и `int_col` до базовых цветовых групп.
3. **Выбор модели:** Рекомендуется использование градиентного бустинга над решающими деревьями (**CatBoost** / **LightGBM**), нативно поддерживающего категориальные признаки высокой размерности без расширения пространства через One-Hot Encoding.
